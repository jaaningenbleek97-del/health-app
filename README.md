# Natura

Local-first natural wellness web app: gentle fitness, vitamins & herbs, exercise reminders, and all-natural remedies. Data stays in your browser — no account.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Add to Home Screen from your phone browser for a PWA-style icon. Reminders use the Web Notification API and work best while the tab is open.

## Safety

Content is general wellness education, not medical advice.
